# POISE SELECT — редактор в Telegram

Что делает бот:
- команда `/new тема` — присылает готовый черновик публикации (заголовок, текст,
  подписи, идею визуала) в голосе и рубриках POISE SELECT;
- ты отвечаешь «да» (сохранить в архив), «нет» (отклонить) или пишешь, что поправить —
  бот переделывает черновик заново;
- `/schedule 10:00` — бот сам присылает дежурный черновик каждый день в это время,
  без напоминаний с твоей стороны.

Я не могу развернуть его на сервере сам — у меня нет доступа к хостингам извне
этого чата. Дальше — единственный путь, без перебора вариантов.

## Шаг 1. Новый Telegram-токен

Старый токен считается скомпрометированным (был на скриншоте). В BotFather:
`/mybots` → выбрать бота → `Bot Settings` → `Revoke current token` → скопировать новый.

**Не присылай мне токен в чат.** Он вставляется напрямую на следующем шаге.

## Шаг 2. Загрузить код на GitHub (без командной строки)

1. Зайти на github.com, создать аккаунт (если ещё нет).
2. Нажать «New repository», назвать `poise-select-bot`, оставить приватным.
3. Кнопка «uploading an existing file» → перетащить туда 3 файла:
   `bot.py`, `requirements.txt`, `Procfile` (все три ниже, в этом чате).
4. Commit changes.

## Шаг 3. Развернуть на Railway (бесплатного лимита хватает с запасом)

1. railway.app → Login with GitHub.
2. New Project → Deploy from GitHub repo → выбрать `poise-select-bot`.
3. Settings → Variables → добавить две переменные:
   - `TELEGRAM_BOT_TOKEN` — новый токен из Шага 1
   - `ANTHROPIC_API_KEY` — ключ с console.anthropic.com (раздел API Keys; это
     отдельный платный по факту использования ключ, не пароль от Claude.ai)
4. Settings → Deploy → Start Command: `python bot.py` (если Railway не подхватил
   Procfile автоматически).
5. Deploy. Бот работает 24/7, без webhook и HTTPS-настроек не требуется.

## Шаг 4. Проверка

Написать боту в Telegram `/start`, затем `/new`. Если пришёл черновик — всё работает.
